# Navigating This Portfolio

**Live site:** https://wiesprakling.github.io/zylahaltes.github.io/

A quick guide to what's on the site and how to get around it.

## Browsing projects

- Each project card shows a title, a short description, tags (skills/tools used), and one or two link buttons:
  - **View live** — opens the deployed project in a new tab
  - **View code** — opens the project's GitHub repo in a new tab
- If a project has more than one screenshot, they're arranged in a small photo grid on the card.
  **Click any image** to open it full-size, then use the **← / →** arrows (or arrow keys, or swipe) to flip through the rest. Press **Esc** or click outside the image to close it.

## Notes

- The site is a single page — everything above lives at the one URL, no separate pages to navigate between.
- Best viewed on desktop or mobile; the layout adapts to the screen automatically.
